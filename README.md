## 주요 기능

### 연주

- **4레인 리듬게임** — 납작한 노트가 내려오면 판정선에 맞춰 누르기. 롱노트는 끝까지 꾹 누르고 있어야 인정. PERFECT · GREAT · GOOD · MISS + FAST · SLOW 표시. 50콤보마다 팀 친구가 응원해요.
- **난이도 8단계** — EASY · NORMAL · HARD · EXPERT · MASTER · EXTREME · INFERNO · CHAOS. EXTREME부터는 곡 자체가 1.1 · 1.15 · 1.25배 빨라져요. 레벨은 초당 노트 수로 자동 계산 (EASY 1~4 … CHAOS 12~20).
- **곡 검색** — 제목 · 작곡가로 찾기, 초성도 돼요 (ㅋㄴ → 캐논).
- **설정** — 노트 속도 · 싱크 · 음악 · 효과음 크기 · 타격음 · 키보드 키 변경(기본 D F J K) · 멀티 공격 키.

### 연주 테마

상점 → 🎨 테마 탭에서 코인으로 사요. 누르면 진짜 게임 화면을 소리 없이 자동 연주로 미리 보여 주고, 그 창에서 사요. 곡 고르는 창의 시작 버튼 옆에서 바로 바꿀 수 있어요. 보기만 바뀌고 점수 · 판정은 그대로예요. 멀티에도 적용돼요.

### 멀티 플레이 (PC · 휴대폰)

- 연주 탭의 멀티 플레이 → 방 만들기(참가 코드 숫자 4자리) · 참가하기. 최대 10명, 빈 자리에 AI 넣기(쉬움 · 보통 · 어려움 · 고수).
- 방장이 곡 · 난이도를 고르고 모두 준비하면 같은 시각에 시작. 공평하게 팀 버프 · 부스터는 꺼져요.
- 연주 중 나오는 **아이템 노트**(약 6.5초마다)를 치면 공격 충전(최대 3번) → Space(휴대폰은 버튼)로 발사: ☁️ 먹구름 · 🌀 어질어질 · ⚡ 번개 속도 · 💣 폭탄 (5초).
- 체력이 0이 돼도 끝까지 연주하지만 그 뒤 점수는 10%만 올라요. 1등이 다음 방장 · 방장 넘기기 · 내보내기 · 종합 순위판 · 30분 동안 연주가 없으면 방이 닫혀요.

### 친구 · 초대

- **친구** — 닉네임으로 신청 · 공개 프로필 · 멀티 방 초대 · 매일 무료 선물(코인 500 + 보석 10) · 코인 · 보석 선물.
- **친구 코드** — 코드(= 100000 + 회원 번호)나 초대 링크(`/?c=코드`)로 가입하면 가입한 친구는 보석 300개 + 바로 서로 친구, 그 친구가 3곡 연주하면 초대한 사람도 보석 300개 (30명까지).
- **점수 자랑 · 공유** — 결과 화면에서 친구들 우편함으로 자랑(하루 5번 · 서버에 있는 최고 기록으로) · 내 친구 코드가 붙은 링크로 공유.

- **팀 편성** — 카드를 꾹 눌러 끌어다 놓기(터치 · 마우스) · 추천 편성 · 보유중 필터 · 정렬.

### 최신 노래는 왜 없나요?

요즘 노래는 작곡 · 작사 저작권(한국음악저작권협회)과 음원 저작인접권(기획사 · 음반사)이 모두 살아 있어서, 웹에 올려 누구나 듣게 하면 둘 다 허락(라이선스)을 받아야 해요. 그래서 이 게임은 저작권이 끝난 곡(작곡가 사후 70년)과 작자 미상 민요, 직접 만든 곡만 넣었어요. 쓸 수 있는 방법은 이 정도예요.

1. **저작권이 끝난 유명곡을 신나게 편곡** (지금 방식) — 비용 0, 바로 가능.
2. **직접 만들었거나 게임 사용이 허락된 음원** — 파일을 주면 BPM을 분석해 채보를 만들어 넣을 수 있어요.
3. **정식 라이선스** — 최신 곡을 넣는 유일한 합법적인 방법. 곡마다 비용과 계약이 필요해요.

유저가 문의하기 → 노래 신청으로 보낸 곡은 관리자 페이지 '노래 신청 순위'에 모여요.

빌드 도구나 프레임워크 없이 동작해요. 의존성은 `@neondatabase/serverless` 하나뿐이에요.

## 어떻게 동작하나요?

### 곡과 채보

곡은 `public/songs.js` 안에 짧은 악보 문자열로 적혀 있어요.

```js
A: ['C|C|G7|C G7',                            // 마디별 코드 진행
    'C5 - - - D5 F5 E5 D5 | G5 - G5 - ...',   // '-' 늘이기, '.' 쉼표
    { bpm: 170, shift: 2, drums: 'fiesta', alt: '받아 치는 가락', harm: false }], // 구간마다 바꿀 수 있는 값
```

1. 같은 악보로 멜로디 · 3도 아래 화음(`harm`) · 받아 치는 가락(`alt`) · 반주 · 신스 베이스 · 드럼을 자바스크립트로 직접 합성해요 (Web Worker에서, PC 0.1~0.3초).
2. 멜로디 음을 노트로 바꿔요. 구절(두 마디)마다 움직이는 방식을 바꿔요: 가락 따라 한 칸씩 · 넓게 건너뛰기 · 한쪽으로 쓸어 가기 · 음 높이대로 자리 잡기.
3. 같은 칸 3연타 · 긴 트릴 · 같은 모양이 연달아 나오는 걸 막아요. 올려 되풀이하는 가락(시퀀스)도 같은 모양으로 보고 손 모양을 바꿔요.
4. 난이도마다 노트 간격 · 동시치기 · 반주 박자 노트를 다르게 넣고, EXTREME부터는 곡을 빠르게 해서, 초당 노트 수로 레벨을 계산해요. 같은 곡 · 난이도면 언제나 같은 채보예요 (씨앗 난수).

### 판정과 점수

| 판정 | 허용 오차 | 점수 비중 |
|---|---|---|
| PERFECT | ±50ms | 100% |
| GREAT | ±100ms | 70% |
| GOOD | ±150ms | 40% |

- 점수 = 1,000,000 × (판정 비중 합 ÷ 판정 수) × (1 + 팀 버프의 '점수 +%'). 롱노트는 누름 + 뗌으로 두 번 판정해요.
- 랭크: S 95만 · A 85만 · B 70만 · C 50만 이상, 나머지 D.

### 카드 점수 · 레벨 업

- 카드 점수 = 등급 기본 점수(일반 100 · 희귀 180 · 영웅 320 · 전설 560 · 신화 1,000 · 초월 12,000) × (1 + (레벨 − 1) × 15%).
- 팀 점수 = 팀 카드 점수 합 × (1 + 시너지 개수 × 10%).
- 레벨 업은 같은 친구 카드 + 코인 (최대 20레벨). 최고 레벨까지 쓸 카드가 다 모였는데 또 나오면 보석으로 돌려줘요.

### 부정 기록 막기

점수는 화면에서 계산해서 보내지만, 서버(`act`의 `finish`)가 받아서 확인해요. 걸리면 저장하지 않고 관리자 '성장 · 보안' 탭에 남겨요.

- 곡을 시작한 기록이 있는지 (싱글은 `start`, 멀티는 방의 판 · 판마다 보상 한 번).
- 클리어라면 곡 길이만큼 시간이 지났는지, 그 시간에 나올 수 있는 판정 수 · 콤보 · 점수인지.
- PERFECT 수 · 팀 버프로 가능한 점수인지, 랭크가 점수와 맞는지.

그 밖에 로그인 실패 제한(10분에 닉네임 10번 · IP 30번, 관리자는 15분에 5번), 가입 IP당 하루 40명, 쿠폰 찍어 맞히기 제한(10분에 10번)이 있어요. 게스트 기록은 기기에만 저장돼서 랭킹에 안 올라가요.

### API

모든 API는 `api/[action].js` 한 함수에서 처리해요.

| 분류 | 경로 |
|---|---|
| 회원 | POST `/api/signup`(친구 코드) · `login` · `logout` · `password` · `rename`, GET `me` · `user`(공개 프로필) |
| 게임 | POST `act`(재화가 바뀌는 모든 행동: `pull` · `pullUntil` · `team` · `levelUp` · `levelUpAll` · `buy` · `claim` · `claimAll` · `mission` · `hello` · `online` · `daily` · `avatar` · `frame` · `theme` · `start` · `finish`), `guest-play`, `client-error` |
| 랭킹 | GET `rank?song=&diff=&period=` · `rank-total?period=` |
| 우편 | GET `mail`, POST `mail-read` · `mail-claim` · `mail-delete` · `coupon` |
| 문의 · 공지 · 상태 | POST `inquiry`, GET `inquiries` · `notices` · `status?v=&s=&d=`(점검 · 예고 · 확률 · 버전 + 접속 신호 · 총 접속 시간) |
| 친구 | GET `friends`, POST `friend-request` · `friend-accept` · `friend-remove` · `friend-gift` · `boast` |
| 멀티 | POST `mp-create` · `mp-join` · `mp-leave` · `mp-set` · `mp-ready` · `mp-start` · `mp-kick` · `mp-bot` · `mp-host` · `mp-invite` · `mp-sync` |
| 관리자 보기 | GET `admin-stats` · `admin-online` · `admin-recent` · `admin-inquiries` · `admin-errors` · `admin-growth` · `admin-user` |
| 관리자 조치 | POST `admin-login` · `admin-logout` · `admin-maintenance` · `admin-preview` · `admin-schedule` · `admin-rates` · `admin-mail` · `admin-notice` · `admin-notice-delete` · `admin-grant` · `admin-room-close` · `admin-coupon` · `admin-inquiry-kind` · `admin-reply` · `admin-user-action` |

### DB 테이블

| 테이블 | 내용 |
|---|---|
| `users` | 닉네임(UNIQUE), scrypt 비밀번호 해시, 저장 데이터(JSONB), 레벨 · 테두리 · 종합 점수, 정지, 임시 비밀번호, 초대한 사람(`ref_by`), 총 접속 시간(`online_secs`) |

| `mail` | 우편 (선물 · 랭킹 알림 · 친구 선물 · 자랑 · 문의 답장) |
| `inquiries` · `notices` | 문의 · 공지사항 |
| `friends` | 친구 관계 · 신청 |
| `presence` | 지금 접속 중 (기기마다 임의 번호 · 회원 · 지금 화면 · 기기 · 마지막 신호) |

| `coupons` · `coupon_uses` | 쿠폰 코드 · 쓴 기록 |
| `name_history` | 닉네임 변경 기록 (이전 · 새 닉네임 · 관리자가 바꿨는지) |

테이블은 버전이 바뀐 뒤 첫 API 요청 때 자동으로 만들어져요. 새 기능은 새 테이블 · 칸만 더하고 기존 회원 데이터는 그대로 이어서 써요.

## 로컬에서 실행하기

```bash
npm install
npx vercel link        # Vercel 프로젝트 연결
npx vercel env pull    # DATABASE_URL 받아오기 (.env.local)
npx vercel dev         # http://localhost:3000
npm test               # 곡 · 채보 · 판정 · 게임 규칙 테스트
```

> ⚠️ `vercel env pull`로 받은 `DATABASE_URL`은 운영 DB일 수 있어요. 그대로 `vercel dev`를 띄우면 표가 바뀌고 회원 데이터에 그대로 저장되니, 개발용 DB(Neon 브랜치)로 바꿔서 쓰세요.

localhost에서 주소에 `?auto`를 붙이면 자동 연주가 돼요 (영상 촬영 · 화면 확인용).

## 배포

GitHub 저장소가 Vercel에 연결돼 있어서 **`main`에 push하면 바로 운영에 배포돼요.** 작업은 브랜치에서 하고, 유저에게 내보낼 준비가 됐을 때 `main`에 합치세요. `npx vercel deploy --prod`로 지금 폴더를 바로 올릴 수도 있어요 (커밋하지 않은 내용도 그대로 올라가요).

- **환경 변수** — `DATABASE_URL`(Marketplace의 Neon Postgres를 연결하면 자동) · `ADMIN_USER` · `ADMIN_PASSWORD`(관리자 계정) · `MAINT_PIN`(점검 모드를 켤 때 비밀번호).
- **새 버전 내기** — `public/rules.js`의 `VERSION`과 `api/[action].js`의 `RELEASE`(공지 내용)를 고쳐서 배포해요. 그러면 첫 요청 때 새 표를 만들고, 공지가 한 번 올라가고, 열려 있던 화면들이 한 번 새로고침돼요.
- **큰 작업 때** — 관리자 페이지에서 점검 모드를 켜 두고, 미리 알리고 싶으면 점검 예고를 보내세요.

## 알려둘 점

- 연주 기록은 서버가 확인하지만([부정 기록 막기](#부정-기록-막기)), 곡 길이만큼 기다렸다가 그럴듯한 값을 보내는 자동 프로그램까지는 못 막아요. 상금이 걸린 랭킹이 되면 입력 기록을 받아 서버에서 다시 채점해야 해요.
- 멀티플레이는 실시간 서버 없이 Postgres와 짧은 폴링(게임 중 0.35초)으로 동작해요. 방이 많아져 DB가 바빠지면 WebSocket 서비스로 옮기면 돼요. 다른 참가자의 작은 화면은 같은 채보를 내 화면에서 그리고 받은 판정만 표시해서, 실제보다 0.6초 늦게 보여요.
- 관리자가 정한 임시 비밀번호는 관리자 화면에 계속 보여 주려고 평문으로 저장해요. 본인이 비밀번호를 바꾸면 지워져요.
- 캐릭터 이미지의 저작권은 원작자(나가노)에게 있으며, 이 프로젝트는 비상업적 팬메이드 작품이에요. 무대 · 계절 · 테마 의상 친구들은 원래 친구 그림에 테마 배경과 소품 배지를 붙인 버전이에요 (새 그림이 생기면 `public/assets/cards/`에 넣고 `rules.js`의 `card`로 연결하면 돼요).
- 수록곡은 모두 저작권이 끝난 클래식 · 민요를 직접 편곡했거나 이 게임용으로 만든 곡이고, 코드로 합성했어요.
